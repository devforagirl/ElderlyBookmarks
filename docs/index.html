Elderly Friendly Bookmarks

Making the web accessible again for our parents and grandparents.

Project Overview

Elderly Friendly Bookmarks is a specialized Chrome extension designed to remove the friction of traditional bookmark management for seniors and visually impaired users. We replace cluttered lists with high-visibility, high-contrast interfaces that prioritize ease of use over complexity.

🖼️ Modern Card View

A visual-first browsing experience with large cards, clear titles, and intuitive action buttons. Perfect for those who prefer visual cues over text lists.

🕒 Timeline View

Automatically organizes bookmarks by date added, allowing users to find "what I saved yesterday" without remembering which folder it went into.

📍 Position Memory

The extension remembers exactly which folder you were in last. No more tedious re-navigation every time you open the manager.

↩️ Natural Navigation

Full support for the browser's "Back" button via URL Hash synchronization, making navigation feel familiar and predictable.

🌍 Global Accessibility

Available in 8 languages with fully adjustable font sizes (up to 100px) and a high-contrast Dark Mode.

🔒 Privacy First

100% local execution. Your data never leaves your machine, and we collect zero telemetry.
